BASES DE DATOS 2 - Práctico 7

Seguridad en Base de Datos - Control de Acceso

Ejercicio 1

Considere la siguiente fracción del esquema del usuario db_instal que registra datos de instalaciones a clientes:


GRANT SELECT ON instalacion TO adm WITH GRANT OPTION;
GRANT UPDATE ON instalacion TO adm WITH GRANT OPTION;
GRANT DELETE ON instalacion TO adm;

Luego, el usuario adm ejecuta:


GRANT SELECT ON instalacion TO doc;
GRANT UPDATE(cantHoras, tarea) ON instalacion TO doc WITH GRANT OPTION;
GRANT DELETE ON instalacion TO doc;

a) Realice el grafo de permisos correspondiente y analice qué sucede en cada caso.

b) Si el usuario db_instal ejecuta REVOKE SELECT ON instalacion FROM adm CASCADE;, ¿qué permisos conserva doc?

Ejercicio 2

Suponga que el usuario U0 es administrador del sistema y quiere controlar el acceso a las tablas Voluntario e Institucion. Complete la sentencia SQL más apropiada para cada caso:

  1. Conceder a U1 todos los privilegios sobre Institucion con posibilidad de delegación.
  2. Permitir que U2 solo consulte la tabla Voluntario.
  3. Permitir que U2 autorice a U3 para insertar en Voluntario.
  4. Retirar el privilegio de borrado sobre Institucion a U1.
  5. Crear un rol ins_prov para insertar datos de provincias y países.

Ejercicio 3

Se tienen los usuarios A, B y C y la tabla Usuario(nro_u, nombre, tarea). Si A ejecuta:


GRANT INSERT ON Usuario TO B WITH GRANT OPTION;
GRANT SELECT ON Usuario TO B WITH GRANT OPTION;
GRANT SELECT ON Usuario TO C;

a) ¿Quién puede ejecutar SELECT * FROM A.Usuario WHERE nro_u='C';?

b) ¿Quién puede ejecutar INSERT INTO A.Usuario VALUES ('C', 'Gerente', 'Control');?

c) ¿Qué sucede si B intenta conceder permisos a D?
