# Guía de estudio: Bases de Datos II

Este sitio reúne apuntes y recursos para repasar los contenidos de la asignatura Bases de Datos II. Está pensado como una guía de consulta y práctica: cada tema incluye apuntes, ejercicios y, cuando corresponde, material complementario.

## Contenidos

La guía está organizada en siete módulos. Cada práctico tiene el mismo número que el módulo al que corresponde:

| Módulo | Tema | Práctico |
| --- | --- | --- |
| 1 | Consultas SQL | [Práctico 1](practice1.html) |
| 2 | Integridad relacional y restricciones declarativas | [Práctico 2](practice2.html) |
| 3 | SQL procedural, funciones y triggers | [Práctico 3](practice3.html) |
| 4 | Vistas | [Práctico 4](practice4.html) |
| 5 | Optimización de consultas e índices | [Práctico 5](practice5.html) |
| 6 | Bases de datos post-relacionales y NoSQL | [Práctico 6](practice6.html) |
| 7 | Seguridad y control de acceso | [Práctico 7](practice7.html) |

Además, el sitio incluye un [cuestionario de autoevaluación](quiz.html), esquemas de bases de datos y materiales adicionales como documentos PDF y videos.

## Cómo abrir el sitio

No requiere instalación ni servidor. Abra `index.html` en un navegador web y desde allí acceda a los apuntes y las prácticas.

Los archivos principales son:

- `index.html`: página de inicio.
- `summary.html`: resumen con enlaces a los módulos, prácticos y recursos.
- `module1.html` a `module7.html`: apuntes de cada módulo.
- `practice1.html` a `practice7.html`: ejercicios correspondientes a cada módulo.
- `quiz.html`: cuestionario de autoevaluación.
- `static/`: hojas de estilo, scripts y materiales complementarios.

Los recursos locales deben permanecer dentro de `static/` para que sus enlaces sigan funcionando. La tipografía del sitio se carga desde Google Fonts, por lo que puede no mostrarse si no hay conexión a Internet; el resto de la guía puede consultarse localmente.
